## Phạm vi dự kiến

Nhóm này cung cấp chiến lược kiểm thử xác định cho stream đồng bộ, bất đồng bộ và phụ thuộc thời gian.

## Các bài trong nhóm

- **[Marble testing](/docs/testing/marble-testing)** — Biểu diễn timeline emission bằng marble syntax.
- **[TestScheduler](/docs/testing/test-scheduler)** — Chạy assertion với virtual time.
- **[Unit test custom operators](/docs/testing/unit-test-operators)** — Kiểm thử operator tùy biến theo input và output.
- **[Kiểm thử async stream](/docs/testing/async-tests)** — Kiểm thử Promise bridge, timer và completion.
- **[Integration tests](/docs/testing/integration-tests)** — Kiểm tra stream tại ranh giới UI, HTTP và service.
